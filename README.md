# Доступ

Android-виджет на рабочий стол: видно, открываются ли в текущей сети
белый список, обычные сайты и обычно заблокированные.

Значок приложения только объясняет, как добавить виджет.
Проверять нужно виджет на домашнем экране.

## Запуск в эмуляторе через Android Studio

Нужны установленные Android Studio и JDK 17.
Эмулятор — Android 8.0 (API 26) или новее.

1. Откройте эту папку как проект в Android Studio и дождитесь синхронизации Gradle.
2. В списке устройств выберите эмулятор телефона.
3. Нажмите Run (зелёный треугольник) или Shift+F10.
4. На домашнем экране эмулятора зажмите пустое место → Widgets →
   **Статус доступа** → перетащите на стол.
5. Нажмите на виджет, чтобы запустить проверку.

Эмулятор ходит в интернет через компьютер, поэтому вердикты — про сеть хоста.
